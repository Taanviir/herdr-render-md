# Render MD has moved

Render MD now lives in [Taanviir/my-herdr-plugins](https://github.com/Taanviir/my-herdr-plugins/tree/main/render-md),
with the other Herdr plugins. This repo is archived.

To switch an existing install:

```bash
herdr plugin uninstall taanviir.render-md
herdr plugin install Taanviir/my-herdr-plugins/render-md
```

Your settings, key bindings and saved state stay where they are.
